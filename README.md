# Obstacle Dodge

This is a simple 3D obstacle-dodging game made in Unity for learning Unity fundamentals. The goal is to move the player through a 3D environment, avoid crashing into obstacles, and understand basic gameplay scripting, movement, and collision handling.

## Gameplay

- Move the player with the keyboard
- Avoid incoming obstacles
- Watch for collision events in the console
- Learn how Unity scripts control player movement and object behavior

## Controls

- W / A / S / D or Arrow Keys: Move the player

## Project overview

This project includes simple Unity scripts for:

- Player movement
- Obstacle interactions
- Collision detection
- Object behavior like falling, spinning, or moving toward the player

## Folder structure

- `Assets/` - Game assets, scripts, and scene files
- `Assets/Scripts/` - C# scripts used for movement and obstacle behavior
- `ProjectSettings/` - Unity project configuration
- `Packages/` - Unity package dependencies

## How to run

1. Open Unity Hub.
2. Click "Open" and select this project folder.
3. Make sure you are using a compatible Unity version (recommend Unity 2022 LTS or newer).
4. Open the main scene in the `Assets` folder.
5. Press the Play button at the top of the Unity editor.

## Build for desktop

1. In Unity, go to `File > Build Settings`.
2. Choose `PC, Mac & Linux Standalone`.
3. Select your target platform.
4. Click `Build` and choose an output folder.

## Learning goals

This project is intended for beginners who want to practice:

- C# scripting in Unity
- Basic player movement
- Collision detection
- Using Unity components like `Transform`, `Input`, and `MonoBehaviour`
- Building a small playable prototype
